# Developer — Sum of Array (Implementation)

## Task

Implement `sum(nums: list[int]) -> int` in Python.

## Inputs

- `output/design.md` — the design to follow

## Output

Write your implementation to `output/tasks/t1/impl.md`.

Format: a markdown file containing the Python function inside a fenced code block.

## Requirements

- Function must be named `sum` and accept `list[int]`, return `int`.
- Handle empty list (return 0).
- Handle negative integers correctly.
- No imports required.
- Keep it simple: a single `return sum(nums)` or an explicit loop is fine.
