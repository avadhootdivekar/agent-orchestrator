# Design Review — Sum of Array

## Task

Review the design document at `output/design.md` and write a brief review.

## Output

Write your review to `output/design-review.md`.

Check:
- Is the function signature correct (`sum(nums: list[int]) -> int`)?
- Are edge cases covered (empty list, negatives)?
- Is the design clear and implementable?

Approve or request changes. Keep the review to a few sentences.
