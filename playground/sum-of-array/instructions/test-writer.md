# Test Writer — Sum of Array

## Task

Write pytest tests for the `sum` function implemented in `output/tasks/t1/impl.md`.

## Inputs

- `output/tasks/t1/impl.md` — the implementation to test

## Output

Write your tests to `output/tasks/t1/tests.md`.

Format: a markdown file containing pytest test functions inside a fenced code block.

## Test cases to cover

- `sum([]) == 0`
- `sum([1, 2, 3]) == 6`
- `sum([-1, 1]) == 0`
- `sum([5]) == 5`
- `sum([-3, -2]) == -5`
